How it works

  1. WriteQwen drafts 32 candidate lines per bar. Each must match the flow template's syllables and stresses and keep the couplet's rhyme.
  2. SpeakMOSS-TTS speaks the chosen line in a cloned voice, continuing from the previous bar's audio so the voice stays consistent.
  3. Lock to the beatMMS forced alignment finds each syllable, and Rubber Band R3 warps it onto its beat position.
  4. PlayThe client plays each bar over the drums on schedule. If the server's audio is late, it plays the same line in eSpeak instead.
