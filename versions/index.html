StreamMUSE Rap Versions

Five versions of the same system, each heard twice on the same 15 prompts: five topics, three flow templates, 16 bars at 90 BPM over the same drums. Every pad under a player is one bar, colored by where that bar's voice came from.

Fake real-timeThe same system with the clock stopped whenever it waits for the server, so every bar gets the server's voice unless the server itself fails. This is what the system can produce.
Real-timeThe demo as it runs live: the Mac client plays on the beat and talks to the H200 over the network. A bar whose voice is late falls back to eSpeak. This is what a listener hears.
